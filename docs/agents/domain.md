# Domain Docs

How the engineering skills should consume this repo's domain documentation when exploring the codebase.

## Before exploring, read these

- **`CONTEXT.md`** at the repo root
- **`docs/adr/`** — read ADRs that touch the area you're about to work in

## File structure

Single-context repo:

```
/
├── CONTEXT.md
├── docs/adr/
│   └── 0001-pure-2d-motion-architecture.md
└── src/
```

## Use the glossary's vocabulary

When naming domain concepts, use the terms defined in `CONTEXT.md`:
- `Hindustan Garage`: The flagship 66-year-old automotive atelier located at 56, M.G. Marg, Civil Lines, Prayagraj.
- `Speed Parts`: The 3-month-old genuine OEM and retail/B2B automotive parts hub at Medical Chauraha, George Town, Prayagraj.
- `Bay`: A designated service or diagnostic station within the workshop (Bays 01 through 06).
- `Cashless Insurance Hub`: Direct claim settlement facility partner for major Indian automotive insurers.
- `Editorial Dual-Contrast`: The aesthetic pairing of Deep Obsidian `#0D0E12` with Warm Editorial Stone `#F4F2EC`.
